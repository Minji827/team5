# 데이터 수집 가이드 (Busan Full-Course · 제5조)

> 지금 단계는 **수집**입니다. 정제·스키마 매핑은 다음 단계에서 진행하니, 지금은 원본 파일을 받아서
> `data/raw/` 아래 올리는 데까지만 하면 됩니다.

## 1. 폴더 구조

```
data/
  raw/
    dongbaekjeon/        # 동백전 가맹점 (데이터 A·김채원)
    sangga/              # 상가정보 분기 CSV (데이터 B·엄유성)
    tourapi/             # TourAPI 관광지·음식점 (데이터 B·엄유성)
    traditional_market/  # 전통시장 표준데이터 (데이터 B·엄유성)
    tour_consumption/    # 관광 데이터랩 소비 (데이터 C·강미)
    visitors/            # 관광공사 방문자 수 (데이터 C·강미)
    population_flow/     # 생활인구 유입·유출 GIS 대시보드 (데이터 C·강미)
    weather/             # 날씨 API/캐시 (데이터 C·강미)
  processed/              # 정제 단계에서 사용 (지금은 비워둠)
```

## 2. 업로드 규칙

| 폴더 | 담당 | 파일명 규칙 |
|---|---|---|
| `dongbaekjeon/` | 데이터 A | `YYYYMMDD_동백전가맹점.csv` |
| `sangga/` | 데이터 B | `YYYYMMDD_상가정보_Q.csv` |
| `tourapi/` | 데이터 B | `YYYYMMDD_tourapi_관광지.csv` |
| `traditional_market/` | 데이터 B | `YYYYMMDD_전통시장.csv` |
| `tour_consumption/` | 데이터 C | `YYYYMMDD_관광데이터랩_소비.csv` |
| `visitors/` | 데이터 C | `YYYYMMDD_방문자수.csv` |
| `population_flow/` | 데이터 C | `YYYYMMDD_생활인구_유입유출.csv`(.geojson) |
| `weather/` | 데이터 C | `YYYYMMDD_날씨.csv` |

- 날짜는 **데이터 기준일** (수집한 날이 아님)
- 받은 원본 그대로 올리기 (가공·정제 금지, 그건 다음 단계)
- 본인 소스 폴더에만 업로드

## 3. AI한테 수집 도움받는 프롬프트 (복붙 1개로 끝)

본인이 맡은 소스를 어디서/어떻게 받아올 수 있는지 모를 때 쓰는 프롬프트입니다.
**정제 요청 아님** — "원본 파일을 어떻게 구해올지"만 물어보는 용도입니다.

```
너는 "Busan Full-Course"(부산 로컬페이 관광소비루트) 프로젝트의 데이터 수집을 돕는 AI야.
지금은 정제 단계가 아니라 "원본 데이터를 구해오는" 수집 단계야.

내가 맡은 데이터 소스: [여기에 본인이 맡은 소스 하나 적기]
(동백전 가맹점 / 상가정보 / TourAPI 관광지 / 전통시장 표준데이터 / 관광데이터랩 소비 /
 관광공사 방문자 수 / 생활인구 유입유출 GIS / 날씨 중 하나)

아래를 도와줘:
1. 이 데이터를 받을 수 있는 공식 출처(사이트·포털·API 이름)와 접속 URL을 알려줘.
2. 다운로드 또는 API 키 발급 절차를 단계별로 알려줘 (가입/신청이 필요하면 그 과정도).
3. 받을 수 있는 파일 형식(CSV/API 응답/GIS)과 대략적인 컬럼 구성을 알려줘.
4. 전국 단위 데이터라면 부산 지역만 받는 방법(필터 옵션)이 있는지 알려줘.
5. 정제나 컬럼 가공은 필요 없어. 원본 파일을 받아오는 것까지만 알려줘.

받은 파일은 내가 data/raw/ 아래 정해진 폴더에 올릴 거야.
```
